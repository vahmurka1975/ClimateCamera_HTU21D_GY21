# ESP32 Climate Camera v1.2.7 (ILI9341 2.4" 320×240 · SHT30)

Прошивка контроллера климатической камеры на базе **ESP32**, дисплея **2.4" TFT SPI 240×320 (`ILI9341` / `ILI9341_2_DRIVER`)** и цифрового датчика температуры и влажности **SHT30** (интерфейс I²C, адрес `0x44`).

Актуальная папка скетча для **Arduino IDE 1.8.19** и **PlatformIO**: **`ClimateCamera_1_2_7_IDE1819`**.

---

## Что нового в версии v1.2.7

1. **Экран-заставка с часами точного времени (NTP) через 1 минуту бездействия:**
   * При отсутствии вращения и нажатий энкодера в течение **60 секунд** (`CLOCK_SCREENSAVER_MS = 60000UL`) дисплей автоматически переключается на полноэкранную заставку с крупными семисегментными часами `ЧЧ:ММ`, мигающим секундным разделителем и двумя нижними капсулами с текущей температурой (`°C`) и влажностью (`%`).
   * Любое вращение или нажатие энкодера мгновенно пробуждает экран и возвращает рабочий интерфейс без ложного срабатывания команд.
   * Автоматическая синхронизация времени по NTP (`pool.ntp.org`, `ru.pool.ntp.org`, `time.nist.gov`) с настраиваемым часовым поясом `CC_TZ_INFO` в `NetworkConfig.h` / `Secrets.h` (по умолчанию `"MSK-3"`).
2. **Повышенная помехоустойчивость датчика SHT30 на кабеле до 150 см:**
   * Программный Open-Drain драйвер `Sht30Reliable` (`SDA = GPIO 21`, `SCL = GPIO 22`, адрес `0x44`) переведён на полупериод тактирования `SHT30_HALF_PERIOD_US = 20` мкс (~25 кГц), что обеспечивает надёжный запас по фронту нарастания сигнала на длинной линии (150 см) с внутренней подтяжкой ESP32 и проверкой контрольной суммы CRC-8.
3. **Надёжное завершение Web OTA (`/update`) и управление сессиями в Web UI:**
   * Перед отправкой файла `.bin` страница `/update` автоматически запрашивает актуальный `X-Climate-Token` через `/api/status?otaToken=...`, исключая ошибку устаревшего токена.
   * На время активной загрузки OTA (`maintenanceActive`) отключаются все реле, освобождается RAM-буфер спрайта дисплея и приостанавливается опрос шины датчика для ускорения записи во Flash.
   * После успешной записи прошивки сервер принудительно сбрасывает буфер сокета (`server.client().flush()`) и выдерживает паузу `2000 мс` перед перезагрузкой, чтобы браузер гарантированно получил подтверждение.
   * В шапку веб-панели добавлены текущее время NTP и кнопки **«Сменить аккаунт»** (`viewer` ↔ `admin`) и **«Выйти»** (`/api/logout`, `/api/reauth`), а также JSON-эндпоинт `/api/time`.
4. **Полный набор встроенных иконок приложения (`FaviconAssets.h`):**
   * Иконки `favicon.ico`, PNG `16×16`, `32×32`, `96×96`, `apple-touch-icon.png` (`180×180`), `192×192`, `512×512` и манифест `/site.webmanifest` хранятся во Flash (`PROGMEM`) и работают без доступа к интернету.

## Основные возможности контроллера

* **Управление температурой и влажностью:**
  * Независимый гистерезис по температуре и влажности, калибровочные поправки датчика `SHT30` (`tempOffset`, `humOffset`) и экспоненциальная фильтрация измерений.
  * Защита компрессора холодильника: стартовая задержка 5 минут, минимальная пауза между включениями 5 минут, минимальное время работы 2 минуты, максимальное непрерывное время работы 40 минут.
  * Импульсный режим работы увлажнителя (30 с работа / 40 с пауза при активном запросе на увлажнение).
* **Отказоустойчивый режим при потере связи с датчиком SHT30:**
  * После 3 последовательных ошибок чтения SHT30 система не останавливает камеру, а переводит компрессор холодильника в безопасный циклический режим (**4 минуты работа / 10 минут пауза**), отключает увлажнитель и сохраняет штатную работу вентилятора. При восстановлении связи с SHT30 камера автоматически возвращается к регулированию по датчику.
* **ПИ-регулятор вентилятора с контролем тахометра:**
  * ШИМ 25 кГц на `GPIO 16` с инверсной характеристикой и обратной связью по тахометру на `GPIO 27` (2 импульса на оборот), детектор остановки крыльчатки (авария при отсутствии оборотов более 10 секунд).
* **Двухъядерная архитектура FreeRTOS:**
  * `Core 1` — цикл климатической автоматики, опрос SHT30, энкодер и отрисовка TFT-дисплея `ILI9341` без мерцания через тайловый спрайт.
  * `Core 0` — Wi-Fi (`STA + резервная точка доступа SoftAP`), веб-сервер, диагностика и обновление прошивки по воздуху (Web OTA).

## Схема подключения (Распиновка ESP32)

### Дисплей 2.4" TFT SPI ILI9341 (240×320)
| Вывод дисплея | Пин ESP32 | Примечание |
| :--- | :--- | :--- |
| `VCC` | `5V` или `3.3V` | Питание модуля |
| `GND` | `GND` | Общий провод |
| `CS` | **GPIO 19** | Выбор кристалла дисплея |
| `RESET / RST` | **GPIO 13** | Аппаратный сброс дисплея |
| `DC / RS` | **GPIO 25** | Команда / Данные |
| `SDI / MOSI` | **GPIO 23** | Шина SPI MOSI |
| `SCK / CLK` | **GPIO 18** | Шина SPI SCLK |
| `LED / BL` | `3.3V` | Подсветка экрана |
| `SDO / MISO` | **Не подключать** | GPIO 19 занят линией `CS` |

### Датчик SHT30, энкодер, вентилятор и модуль реле
| Узел | Пин ESP32 | Назначение |
| :--- | :--- | :--- |
| `SHT30 SDA / SCL` | **GPIO 21 / GPIO 22** | Шина I²C датчика SHT30 (адрес `0x44`) |
| `Энкодер CLK / DT / SW` | **GPIO 32 / 33 / 4** | Поворот и кнопка энкодера |
| `Вентилятор PWM` | **GPIO 16** | ШИМ 25 кГц управления скоростью |
| `Вентилятор TACH` | **GPIO 27** | Тахометр (2 импульса на оборот) |
| `Реле IN1` | **GPIO 15** | Питание вентилятора |
| `Реле IN2` | **GPIO 17** | Увлажнитель |
| `Реле IN3` | **GPIO 14** | Резерв (всегда выключен) |
| `Реле IN4` | **GPIO 26** | Компрессор холодильника |

## Сборка и загрузка прошивки

### Вариант 1. PlatformIO
В корне архива расположен готовый `platformio.ini`, который автоматически подключает `User_Setup.h` и схему разделов `min_spiffs.csv`:
```bash
pio run -t upload
```

### Вариант 2. Arduino IDE 1.8.19
1. Установите ядро **Arduino-ESP32 `2.0.17`** и библиотеку **TFT_eSPI `2.5.43`**.
2. Скопируйте файл `TFT_eSPI_setup/User_Setup.h` в папку `Documents/Arduino/libraries/TFT_eSPI/User_Setup.h` с заменой.
3. Проверьте настройки сети, часового пояса (`CC_TZ_INFO`) и пароли в `ClimateCamera_1_2_7_IDE1819/Secrets.h`.
4. Откройте `ClimateCamera_1_2_7_IDE1819/ClimateCamera_1_2_7_IDE1819.ino`.
5. Выберите плату `ESP32 Dev Module` и схему разделов `Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)`.

## Настройка удалённого доступа на роутере TP-Link EC225-G5
Подробная пошаговая инструкция находится в файле **`TP_LINK_EC225_G5_GUIDE.md`** в корне архива:
1. В `Secrets.h` задан статический IP `192.168.0.150` (шлюз `192.168.0.1`).
2. В настройках роутера TP-Link EC225-G5 (**Дополнительные настройки → Сеть → Сервер DHCP → Резервирование адресов**) закрепите IP `192.168.0.150` за MAC-адресом ESP32.
3. В разделе **Дополнительные настройки → Переадресация NAT → Виртуальные серверы** добавьте правило:
   * **Внешний порт:** `8080`
   * **Внутренний IP:** `192.168.0.150`
   * **Внутренний порт:** `80`
   * **Протокол:** `TCP`
4. Откройте из интернета `http://ВАШ_СТАТИЧЕСКИЙ_IP:8080/` и войдите под логином `viewer` (мониторинг) или `admin` (управление).
