# Инструкция по настройке удалённого мониторинга через роутер TP-Link EC225-G5

Данное руководство описывает пошаговую настройку контроллера **ESP32 Climate Camera v1.2.3** и гигабитного роутера **TP-Link EC225-G5** при наличии статического («белого») внешнего IP-адреса от провайдера.

---

## Шаг 1. Настройка прошивки ESP32 (`Secrets.h`)
1. В папке `ClimateCamera_1_2_3_IDE1819` откройте файл `Secrets.h`.
2. Пропишите имя и пароль вашей домашней сети Wi-Fi **2.4 ГГц** (`CC_WIFI_SSID`, `CC_WIFI_PASS`).
3. Проверьте настройки статического локального IP (по умолчанию у роутеров TP-Link EC225-G5 подсеть `192.168.0.x`, шлюз `192.168.0.1`):
   ```cpp
   #define CC_USE_STATIC_IP 1
   #define CC_STATIC_IP      192, 168, 0, 150
   #define CC_STATIC_GATEWAY 192, 168, 0, 1
   #define CC_STATIC_SUBNET  255, 255, 255, 0
   #define CC_STATIC_DNS     192, 168, 0, 1
   ```
4. Задайте надёжные пароли:
   * `CC_ADMIN_USER` / `CC_ADMIN_PASS` — полный доступ (управление и изменение уставок).
   * `CC_VIEWER_USER` / `CC_VIEWER_PASS` — безопасный режим **«Только мониторинг»** для входа с телефона через интернет.

---

## Шаг 2. Резервирование IP-адреса в DHCP роутера TP-Link EC225-G5
1. Войдите в панель роутера: `http://192.168.0.1` (или `http://tplinkwifi.net`).
2. Перейдите в **Дополнительные настройки (Advanced)** → **Сеть (Network)** → **Сервер DHCP (DHCP Server)** (или **Настройки LAN / LAN Settings**).
3. В разделе **Резервирование адресов (Address Reservation)** нажмите **Добавить (Add)**.
4. Укажите **MAC-адрес** вашего ESP32 (отображается в подвале веб-интерфейса камеры и в Serial Monitor) и IP-адрес **`192.168.0.150`**.
5. Включите запись и нажмите **Сохранить (Save)**.

---

## Шаг 3. Проброс порта (Виртуальные серверы / Virtual Servers)
1. В верхнем меню роутера откройте **Дополнительные настройки (Advanced)**.
2. В левом меню выберите **Переадресация NAT (NAT Forwarding)** → **Виртуальные серверы (Virtual Servers)**.
3. Нажмите **Добавить (Add)** и заполните поля:
   * **Тип сервиса (Service Type):** `ClimateCamera`
   * **Внешний порт (External Port):** `8080` *(рекомендуется нестандартный порт вместо 80)*
   * **Внутренний IP (Internal IP):** `192.168.0.150`
   * **Внутренний порт (Internal Port):** `80`
   * **Протокол (Protocol):** `TCP`
4. Поставьте галочку **Включить (Enable This Entry)** и нажмите **Сохранить (Save)**.

---

## Шаг 4. Подключение из интернета
Откройте в браузере на смартфоне или компьютере:
```text
http://ВАШ_СТАТИЧЕСКИЙ_ВНЕШНИЙ_IP:8080/
```
* Для просмотра параметров климата и журнала событий без риска случайного нажатия кнопок входите под логином **`viewer`**.
* Для изменения уставок температуры/влажности или управления системой входите под логином **`admin`**.
