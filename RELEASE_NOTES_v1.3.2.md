# Release Notes — ClimateCamera v1.3.2 (HTU21D / GY-211)

## Ключевые изменения в версии 1.3.2

1. **Драйвер `Htu21dReliable` (`HTU21D (GY-211)`, I²C `0x40`):**
   * Файлы драйвера переименованы в `Htu21dReliable.h` и `Htu21dReliable.cpp`.
   * Класс `Htu21dReliable`, методы и функции `initHTU21D()`, `readHTU21D()`, `htu21dCrc8()`, константы `HTU21D_ADDR = 0x40` и `HTU21D_HALF_PERIOD_US = 20`.
   * Полностью удалены все упоминания старого названия датчика из кода, Web UI, Serial-команд и документации.

2. **Обновлённый экран часов (`ILI9341 320×240`) с датой `дд.мм.гггг`:**
   * Новый визуальный стиль карточки часов `drawClockScreen()` с двойной рамкой, улучшенной геометрией 7-сегментных цифр с подсветкой, секундным прогресс-баром и компактным отображением текущей даты в формате `дд.мм.гггг` мелким шрифтом.

3. **Реальные дата и время в журнале событий:**
   * Каждое событие содержит штамп `epoch` (`uint32_t`) и автоматически пересчитывается по NTP даже для стартовых событий, записанных до синхронизации времени.
   * Отображение реальной даты и времени (`ДД.ММ.ГГГГ ЧЧ:ММ:СС`) на экране камеры, в таблице Web UI и при экспорте `.txt`.

4. **Вкладка «Контроль за весом продукта» на 30 продуктов:**
   * Энергонезависимое хранение в NVS (`Preferences`) до 30 продуктов (`Продукт №1` .. `Продукт №30`) и до 32 контрольных взвешиваний на каждый продукт.
   * Кнопка «Загрузить новый продукт» с автовыбором свободного слота, вводом начального веса в граммах и выбором даты закладки через календарь.
   * Автоматическая подстановка текущей даты при контрольном взвешивании, расчёт процента усушки и прогнозируемой даты готовности.
   * Отдельное модальное окно «История взвешиваний» со всеми замерами в памяти и кнопка «Извлечь продукт» для очистки слота.
